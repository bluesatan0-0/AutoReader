# WebpageAutoScrollNext
一个轻量、优雅的浏览器油猴脚本，为所有网页提供丝滑自动滚动体验，并智能识别"下一页/下一章"按钮实现自动翻页。

![version](https://img.shields.io/badge/version-2.2-blue)
![license](https://img.shields.io/badge/license-MIT-green)

## ✨ 功能特性

- **全局可用** — 适配所有网站，面板自动吸附屏幕左右边缘
- **丝滑滚动** — 基于 `requestAnimationFrame`，1~100 级速度无级调节，帧率无关的匀速体验
- **智能记忆** — 每个域名的滚动速度、跳转延迟、空格键开关、自动跳转开关独立保存，互不干扰
- **提前视口触发** — 下一页按钮进入视口底部 30% 区域即自动停止并准备跳转，无需被迫看完底部广告和推荐
- **自动下一页（手动开启）** — 滚到"下一章"按钮出现时自动停止并延迟跳转，支持小说站、漫画站等；**默认关闭**，需手动开启，避免误跳转
- **顶/底快捷键** — 面板附带 ↑ ↓ 按钮，一键跳转页面顶部或底部
- **空格键快捷滚动** — 悬浮面板上直接开关，开启后按空格快速启停（默认关闭，避免与视频播放、富文本编辑、游戏等冲突）
- **回车启动** — 在速度输入框按 Enter 直接开始滚动
- **自定义选择器** — 当自动检测不准时，可为特定网站配置精确的 CSS 选择器，支持 `|` 字符转义
- **半透明不遮挡** — 深色毛玻璃 UI，面板与按钮均使用低透明度，正文内容清晰透出
- **安全性加固** — 自动过滤 `javascript:`、`data:`、`vbscript:`、`file:` 等危险协议，防止恶意跳转
- **性能优化** — 分层 DOM 扫描策略，优先搜索语义化导航区域，大幅减少 CPU 占用

## 📦 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey / Greasemonkey）
2. [点击此处安装脚本](https://update.greasyfork.org/scripts/562875/%E7%BD%91%E9%A1%B5%E7%BB%99%E6%88%91%E6%BB%9AAuto%20Scroll.user.js)

## 🎮 使用说明

| 操作 | 说明 |
|------|------|
| 点击 ▶ / ■ | 开始 / 停止滚动 |
| 按 `Space` | 全局快捷键启停（输入框内除外，需先在面板开启「空格键」开关） |
| 输入速度按 `Enter` | 保存速度并立即开始滚动 |
| 拖拽面板 | 可吸附到屏幕左侧或右侧，位置自动记忆 |
| 点击 ↑ / ↓ | 快速跳转页面顶部 / 底部 |
| 点击 ⚙ | 打开配置面板 |
| 点击「空格键」开关 | 开启/关闭空格键快捷滚动（默认关闭） |
| 点击「自动跳转」开关 | 开启/关闭滚动到末尾时自动翻页/下一章（默认关闭） |
| 鼠标离开面板 | 1.2 秒后自动收缩为迷你按钮 |

## ⚙️ 配置面板

点击面板右上角的 **⚙** 打开配置：

### 1. 自定义选择器
当某些网站的"下一页"按钮无法被自动检测时，可添加规则：

- **域名模式**：如 `*qidian.com*`（`*` 为通配符）
- **CSS选择器**：如 `a#nextChapter`、`.bottem2 a:nth-child(3)`
- **文本关键词**：可选，用于二次校验按钮文字
- **转义支持**：若选择器或关键词中本身包含 `|` 字符，请使用反斜杠转义：`\|`

### 2. 跳转延迟
- 范围：0 ~ 10 秒，步进 0.5 秒
- 默认：2 秒
- **按域名独立保存**，不同网站可设置不同等待时间

## 🧠 自动下一页原理

脚本采用**分层扫描策略**实时检测页面中的"下一章/下一页"按钮：

1. **第一层**：优先扫描语义化导航区域（`nav` / `article` / `footer` / 含 `page/chapter/nav` 的 class/id），命中率高且节点极少
2. **第二层**：补充扫描全文档的 `<a>` / `<button>` 等交互元素
3. **第三层**：兜底扫描 `div/span/p` 等容器，但过滤尺寸小于 20px 的无意义文本节点

当按钮**进入视口底部 30% 区域**时（或页面已滚到底时），且**「自动跳转」开关已开启**：

1. 立即停止滚动
2. 等待设定的延迟时间（给用户阅读末尾内容的时间）
3. 自动点击按钮跳转（危险协议会被安全拦截）
4. 新页面加载后自动恢复之前的滚动状态

> ⚠️ **注意**：自动跳转默认关闭，需在主面板手动开启「自动跳转」开关。关闭后滚动至底部仅停止，不会触发任何页面跳转。

### 支持的按钮文本（自动检测）
`下一章`、`下一页`、`下一话`、`next_chap`、`next chapter`、`下一回`、`下一卷`、`下一篇`、`下章`、`下页`、`次の章`、`다음 화` 等。
